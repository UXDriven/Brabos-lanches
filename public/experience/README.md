# Brabos Experience — protótipo visual 2.5D

Experiência scroll-driven em HTML/CSS/JS sem dependências de build. Os ingredientes foram recortados de uma imagem conceitual gerada para o projeto. **Não é um modelo 3D verdadeiro nem representa fotos reais dos produtos da Brabos.**

## Executar

Na pasta do projeto: `python -m http.server 8080` e abra http://localhost:8080.

## Publicar na Vercel

Importe esta pasta como um projeto estático (Framework: Other, sem build command e sem output directory) ou copie os arquivos para a raiz de um repositório de deploy estático. Não sobrescreva o projeto Next.js atual sem testar o preview primeiro.

## Pendências para produção

Validar em dispositivos reais, ajustar os recortes/halos das camadas e confirmar a fidelidade visual; caso se deseje 3D verdadeiro, substituir as camadas por modelos 3D texturizados. Projeto conceitual não oficial.
